# MiniCraft
three.js + WebSocket のMinecraft風マルチプレイ・ボクセルゲーム(Node.js + `ws` のみ)。

## 主な機能
- 複数ワールド(名前+シードで作成、`data/<名前>.json` に保存)/ バイオーム(平原・砂漠・雪原・森・海)/ 洞窟・溶岩
- ブロック13種(TNT・水・溶岩・レッドストーンブロック・雪など)/ インベントリ
- ゲームモード: クリエイティブ / サバイバル(ハート・落下/溶岩/爆発/PvPダメージ)/ スペクテイター
- スニーク(Shift、端から落ちない)/ スマホ・タブレット用タッチ操作 / 天気(雨)
- チャットとコマンド(`T` または `/`、Tabで補完): `/help` で一覧(tp・tphere・tpall・give・fill・setblock・home・msg・kick など)
- 採掘アニメーション(ヒビ割れ)/ 掘る・スニークのモーション / 管理画面(パスワード一致で自動遷移)
- キャラクリ / 頭上ネームタグ / 座標コピー(`C` キー、`/coords`、設定画面)

## 追加機能メモ
- 視点切替: `V` キー(一人称 / 三人称後ろ / 三人称前)。スマホは「視点」ボタン
- クラフト: `E` で2×2、作業台を右クリックで3×3。作業台・棒・ツルハシ・各ブロックのレシピ。クリエイティブは素材が無限
- シードは固定(環境変数 `SEED`、未設定なら `MiniCraft`)。変更は管理画面のみ
- ワールド保存: サーバーが `data/` に自動保存(終了時も保存)、管理画面でバックアップのダウンロード/読み込み、プレイヤーの位置・持ち物はブラウザに自動保存
- 水とマグマは流れるほど水位が下がる(最大7マス)

## 起動
```bash
npm install && npm start    # http://localhost:3000
```

## 環境変数
| 名前 | 説明 |
|---|---|
| `SEED` | 新規ワールド作成時の既定シード(空ならランダム) |
| `ADMIN_KEY` | 設定すると、シード変更(`/seed 値`・設定画面)に `/op キー` が必要になる |
| `DATA_DIR` | ワールド保存先(Render Disk のマウント先など) |

## Render
GitHubにpush → New Web Service(Build `npm install` / Start `node server.js` / Health `/healthz`)。
無料プランのファイルは一時的で、再起動でワールドが消えます。

## 管理者キー
`ADMIN_KEY` は **環境変数** で設定します(Render → Environment)。コードやGitHubには書かないでください。
設定すると、`/seed 値` や設定画面のシード変更に、ゲーム内で `/op キー` による認証が必要になります。

管理画面は、メニュー(Esc)の「管理画面」からパスワードを入力すると、一致した時点で自動的に開きます。
